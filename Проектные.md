**!! моя иишка**

1. Сделать отдельного агента [qa.md](http://qa.md)Не дефолтный ассистент, а жёстко заточенный промпт:

- роль: senior QA / test engineer
- всегда думает в терминах: риски, edge cases, reproducibility, severity/priority
- сначала собирает контекст (требования → код → существующие тесты → diff)
- выдаёт структурированный результат (чек-листы, тест-кейсы, баг-репорты, gaps)

2. Набор skills под реальные сценарии QAСамое ценное, что можно сделать прямо сейчас (без нового кода):


| **Skill**               | **Что делает**                                             |
| ----------------------- | ---------------------------------------------------------- |
| review-commit           | Ревью одного коммита с фокусом на риски и пробелы в тестах |
| test-cases-from-feature | Генерирует тест-кейсы по описанию/коду фичи                |
| bug-report              | Форматирует баг (steps, expected/actual, env, severity)    |
| regression-check        | По diff/истории ищет, что могло сломаться                  |
| coverage-gaps           | Смотрит код + тесты и говорит, чего не хватает             |
| api-checklist           | Чеклист для API (auth, validation, errors, idempotency…)   |
| exploratory             | Сессия исследовательского тестирования по области          |
