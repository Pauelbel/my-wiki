# 2026-09-23 - Настройки LM Studio

## Исходный текст

Вот все настройки, которые мы прошли, одной таблицей.

Раздел	Параметр	Значение	Зачем
Context and Performance	Automatic Optimize Based on Hardware	Выкл	Чтобы задать контекст и выгрузку вручную
Context Length	32768	Хватает агенту с двойным запасом и влезает в 16 ГБ
GPU Offload	48 (максимум)	Вся модель на RTX 5080
CPU Thread Pool Size	10	Два ядра остаются системе
Evaluation Batch Size	2048	По умолчанию, не трогаем
Physical Batch Size	512	По умолчанию, не трогаем
Max Concurrent Predictions	2	Запас на второго агента
Flash Attention	Вкл	Экономит видеопамять на длинном контексте
Generation	Temperature	0.2	Предсказуемое поведение агента
Limit Response Length	Выкл	Не обрезаем ответы
Context Overflow	Stop at Limit	Явная ошибка вместо тихой потери контекста
Stop Strings	Пусто	Не нужны
Reasoning	Reasoning Budget	4096	Меньше расход контекста на размышления
Reasoning Budget Message	I have to answer now.	По умолчанию
Memory	Offload KV Cache to GPU Memory	Вкл	Кэш на видеокарте
Unified KV Cache	Вкл	По умолчанию
Context Checkpoints	32	По умолчанию
K Cache Quantization Type	Q8_0	Примерно вдвое меньше памяти под контекст
V Cache Quantization Type	Q8_0	То же
Keep Model in Memory	Вкл	Модель не выгружается между запросами
Try mmap()	Вкл	Быстрая загрузка с диска
Speculative Decoding	Speculative Decoding	Off	Нет свободной памяти под вторую модель
Sampling	Top K	64	По умолчанию
Top P	0.95	По умолчанию
Min P	0.05	По умолчанию
Repeat Penalty	1.1	Выше не поднимать, иначе агент начнёт коверкать пути
Presence Penalty	Выкл	Вредит агенту
Frequency Penalty	Выкл	Вредит агенту
Для аналитического агента температуру 0.3–0.4 лучше задавать отдельно в его запросе, а здесь оставить 0.2.
