# 2026-09-23 - Настройки LM Studio для агента

## Исходный текст

Настройка	Значение	Почему
Automatic Optimize Based on Hardware	Выкл	Иначе LM Studio сам выбирает контекст и выгрузку, и вы не знаете реальных значений
Context Length	32768	Хватает агенту с двойным запасом и помещается в 16 ГБ VRAM вместе с моделью
GPU Offload	48 (максимум)	Все слои на RTX 5080; на CPU работало бы в десятки раз медленнее
CPU Thread Pool Size	10	При полной выгрузке на GPU почти не влияет; 2 ядра остаются системе
Evaluation Batch Size	2048	Стандарт: быстро читает промпт без лишнего расхода памяти
Physical Batch Size	512	Стандарт для отправки данных в видеокарту
Max Concurrent Predictions	1	Один агент получает весь контекст; слоты делят память между собой
Flash Attention	Вкл	Сильно экономит память на длинном контексте; обязателен для квантования V-кэша
Temperature	0.4	Низкая случайность = предсказуемое поведение. Для Архивариуса лучше 0.2, 0.4 — под аналитика
Limit Response Length	Выкл	Ограничение может оборвать ответ агента на середине
Context Overflow	Stop at Limit	Явная ошибка вместо тихой потери плана и результатов инструментов
Stop Strings	Пусто	Нужны только для отсечения мусорных тегов; иначе обрезают ответы
Reasoning Budget	4096	Хватает для процедурной задачи и не съедает контекст
Reasoning Budget Message	I have to answer now.	Служебная фраза при исчерпании лимита, менять не нужно
Offload KV Cache to GPU Memory	Вкл	Кэш контекста на видеокарте работает быстрее
Unified KV Cache	Вкл	Общий кэш для слотов, эффективнее расходует память
Context Checkpoints	32	Значение по умолчанию
K Cache Quantization Type	Q8_0	Примерно вдвое экономит память кэша почти без потери качества
V Cache Quantization Type	Q8_0	То же; Q4 уже заметно ухудшает качество
Keep Model in Memory	Вкл	Модель не перезагружается между запросами агента
Try mmap()	Вкл	Быстрая загрузка модели с NVMe
Speculative Decoding	Off	Нужна вторая модель, а свободной VRAM нет
Top K Sampling	64	По умолчанию; при низкой температуре почти не влияет
Top P Sampling	0.95	Стандарт; при низкой температуре почти не срабатывает
Min P Sampling	0.05	Стандарт; отсекает явно слабые варианты
Repeat Penalty	1.1	Мягкий штраф; выше начнёт коверкать повторяющиеся пути и имена файлов
Presence Penalty	Выкл	Толкает модель уходить от темы, агенту вредно
