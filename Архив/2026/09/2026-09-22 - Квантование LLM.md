# Квантование LLM

Таблица обозначений и типов квантования для моделей больших языковых моделей (LLM).

| Обозначение | Что означает | По-простому |
| :--- | :--- | :--- |
| `Q` | Quantization | Модель сжата за счет снижения точности весов |
| `2 / 3 / 4 / 5 / 6 / 8` | Количество бит | Чем больше число, тем выше качество и больше размер |
| `K` | K-quants | Более качественная схема квантования из llama.cpp |
| `_S` | Small | Самый компактный вариант данного кванта |
| `_M` | Medium | Баланс размера и качества |
| `_L` | Large | Более качественный, но более тяжелый вариант |
| `Q2_K` | 2-битный K-quant | Очень маленький, качество заметно страдает |
| `Q3_K_S` | 3-bit Small | Очень компактный, когда памяти совсем мало |
| `Q3_K_M` | 3-bit Medium | Чуть лучше качества, чем `Q3_K_S` |
| `Q3_K_L` | 3-bit Large | Лучший среди Q3, но уже тяжелее |
| `Q4_K_S` | 4-bit Small | Хорошее качество, экономит память |
| **`Q4_K_M`** | **4-bit Medium** | **Лучший универсальный баланс, обычно начинать с него** |
| `Q5_K_S` | 5-bit Small | Выше качество Q4, немного больше памяти |
| `Q5_K_M` | 5-bit Medium | Хороший вариант, если модель спокойно помещается |
| `Q6_K` | 6-bit | Очень небольшая потеря качества, но заметно тяжелее |
| `Q8_0` | 8-bit | Почти исходное качество, большой размер |
| `F16 / FP16` | 16-bit float | Практически исходные веса, очень много памяти |
| `BF16` | Brain Float 16 | Еще один 16-битный формат исходных весов |
| `IQ...` | Importance Quantization | Более новые алгоритмы квантования, особенно полезны на очень низких битах |
