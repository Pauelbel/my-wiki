### Шпаргалка по uv

**Установка uv**

```
# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
# Mac / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
# или через pip
pip install uv

uv --version        # проверить
uv self update      # обновить сам uv
```

**Новый проект (рекомендуемый способ)**

```
uv init myproject   # создать проект с pyproject.toml
cd myproject
uv add requests     # добавить библиотеку (сам создаст .venv)
uv add --dev pytest # добавить зависимость для разработки
uv remove requests  # удалить библиотеку
uv run main.py      # запустить скрипт в окружении проекта
uv sync             # восстановить окружение по pyproject.toml (например, на другой машине)
uv lock             # обновить lock-файл
uv tree             # дерево зависимостей
```

**Классическая схема (как с pip)**

```
uv venv                          # создать .venv в текущей папке
uv venv --python 3.12            # с нужной версией питона
uv pip install requests          # поставить пакет
uv pip install -r requirements.txt
uv pip freeze > requirements.txt
uv pip list
uv pip uninstall requests
```

Активация, если нужна: `.venv\Scripts\activate` (Windows) или `source .venv/bin/activate` (Mac/Linux).

**Программы и инструменты (аналог pipx)**

```
uvx ruff check .                 # запустить без установки
uv tool install ruff             # установить глобально, в отдельное окружение
uv tool list                     # что установлено
uv tool upgrade ruff
uv tool uninstall ruff
```

**Версии питона**

```
uv python list                   # доступные и установленные
uv python install 3.12           # поставить версию
uv python pin 3.12               # закрепить версию за проектом
```

**Basic Memory**

```
uv tool install basic-memory --prerelease=allow
uv tool upgrade basic-memory --prerelease=allow
uvx basic-memory mcp             # так его запускает VS Code
```

Флаг `--prerelease=allow` для Basic Memory обязателен, без него поставится старая версия.
