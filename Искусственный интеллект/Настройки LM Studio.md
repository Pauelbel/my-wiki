# Настройки LM Studio

Таблица настроек для оптимальной работы агента в LM Studio:

| Раздел | Параметр | Значение | Зачем |
| :--- | :--- | :--- | :--- |
| Context and Performance | Automatic Optimize Based on Hardware | Выкл | Автоподбор контекста и выгрузки на GPU под железо |
| Context and Performance | Context Length | 32768 | Сколько токенов модель держит в памяти: промпт, история, результаты инструментов |
| Context and Performance | GPU Offload | Максимум | Сколько слоёв модели считается на видеокарте, остальные — на CPU |
| Context and Performance | CPU Thread Pool Size | 10 | Сколько потоков процессора используется для вычислений |
| Context and Performance | Evaluation Batch Size | 2048 | Сколько токенов промпта обрабатывается за один заход; влияет на скорость чтения входа |
| Context and Performance | Physical Batch Size | 512 | Размер порции, реально отправляемой в видеокарту внутри батча |
| Context and Performance | Max Concurrent Predictions | 2 | Сколько запросов модель обрабатывает одновременно |
| Context and Performance | Flash Attention | Вкл | Оптимизация внимания: тот же результат при меньшем расходе памяти |
| Generation | Temperature | 0.2 | Степень случайности выбора слов: ниже — предсказуемее, выше — разнообразнее |
| Generation | Limit Response Length | Выкл | Ограничение длины ответа в токенах |
| Generation | Context Overflow | Stop at Limit | Что делать при переполнении контекста: остановиться или выбросить часть истории |
| Generation | Stop Strings | Пусто | Строки, при появлении которых генерация обрывается |
| Reasoning | Reasoning Budget | 4096 | Лимит токенов на размышления модели перед ответом |
| Reasoning | Reasoning Budget Message | I have to answer now. | Фраза, которую модель получает при исчерпании лимита размышлений |
| Memory | Offload KV Cache to GPU Memory | Вкл | Хранить кэш контекста в видеопамяти, а не в оперативной |
| Memory | Unified KV Cache | Вкл | Общий кэш контекста для всех параллельных запросов вместо отдельного на каждый |
| Memory | Context Checkpoints | 32 | Сохранённые точки кэша для быстрого продолжения без повторной обработки промпта |
| Memory | K Cache Quantization Type | Q8_0 | Сжатие ключей в кэше контекста для экономии памяти |
| Memory | V Cache Quantization Type | Q8_0 | Сжатие значений в кэше контекста для экономии памяти |
| Memory | Keep Model in Memory | Вкл | Не выгружать модель из памяти между запросами |
| Memory | Try mmap() | Вкл | Загружать модель через отображение файла в память: быстрее старт |
| Memory | Speculative Decoding | Off | Ускорение: маленькая модель предсказывает токены, основная проверяет их пачкой |
| Sampling | Top K | 64 | Сколько самых вероятных вариантов рассматривается на каждом шаге |
| Sampling | Top P | 0.95 | Отбор вариантов, пока их суммарная вероятность не достигнет порога |
| Sampling | Min P | 0.05 | Отсечение вариантов, слишком маловероятных по сравнению с лучшим |
| Sampling | Repeat Penalty | 1.1 | Штраф за повтор уже использованных токенов, растёт с частотой повтора |
| Sampling | Presence Penalty | Выкл | Разовый штраф за любое уже встречавшееся слово; толкает к новым темам |
| Sampling | Frequency Penalty | Выкл | Штраф, пропорциональный числу повторов слова |

**Примечание:** Для аналитического агента температуру 0.3–0.4 лучше задавать отдельно в его запросе, а здесь оставить 0.2.
